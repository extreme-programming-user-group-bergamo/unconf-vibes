# Story 5.8: Cancel Command

**Status:** Done

**Epic:** 5 - Organizer Tools & Hotel Automation

**Issue Type:** Story

---

## Story

**As an** attendee,  
**I want** a safe and explicit `unconf cancel` flow,  
**so that** I can cancel my current booking without ambiguity and immediately free the room.

---

## Acceptance Criteria

1. `unconf cancel` cancels the current booking.
2. Default behavior requires explicit irreversible confirmation before execution.
3. Cancellation is sent through the backend API (no direct CLI-side data mutation).
4. Successful cancellation removes the booking from active room occupancy.
5. Existing roommate-preservation behavior remains intact for remaining occupants.
6. `--yes` flag skips interactive confirmation for scripted/power-user flows.
7. CLI returns a clear success outcome and `unconf status` reflects no active booking after cancellation.
