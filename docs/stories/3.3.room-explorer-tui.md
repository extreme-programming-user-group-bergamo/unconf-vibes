# Story 3.3: Room Explorer TUI

**Status:** Done

**Epic:** 3 - Room Exploration & Booking

**Issue Type:** Story

---

## Story

**As an** attendee,  
**I want** to run `unconf rooms` to explore available rooms interactively,  
**so that** I can see options and make an informed choice.

---

## Acceptance Criteria

1. `unconf rooms` launches interactive TUI (requires conference context)
2. Rooms displayed in scrollable list with: room number, type, price, availability (e.g., "2/3 spots")
3. Room occupants shown (names for Public, "Private attendee" for Private)
4. Filter by room type (single/double/triple) via keyboard shortcut
5. Sort by price or availability
6. Press Enter on room to initiate booking flow
7. Press 'q' to exit TUI
8. Context indicator shown in header

### Data and API Notes

- Room listing is retrieved from `GET /conferences/{slug}/rooms` via CLI client and includes room pricing, capacity, spots taken/available, and occupant display data.
- Occupant visibility requirements are privacy-aware: public names displayed, private attendees masked.
- Room data model fields required for rendering include room number, room type, price per night, and capacity-derived availability.
- **Reference:** [docs/prd/epic-3-room-exploration-booking.md#story-31-room-data-model--api](../prd/epic-3-room-exploration-booking.md#story-31-room-data-model--api), [docs/architecture/4-data-models.md#44-room](../architecture/4-data-models.md#44-room), [docs/architecture/4-data-models.md#45-booking](../architecture/4-data-models.md#45-booking)
