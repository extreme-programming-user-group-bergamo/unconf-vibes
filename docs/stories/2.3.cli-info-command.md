# Story 2.3: CLI Info Command

**Status:** Done

**Epic:** 2 - Conference Discovery & Context

---

## Story

**As an** attendee,
**I want** to run `unconf info <conference-slug>` to see details about a conference,
**so that** I can learn more before committing.

---

## Acceptance Criteria

1. `unconf info <conference-slug>` displays detailed conference information
2. Shows: name, description, dates, location, capacity, current attendee count
3. Shows room types available with price ranges
4. If context is set, `unconf info` (no argument) shows current context conference
5. Error message if conference slug not found
6. Works without authentication (public data)

---

## Scope Clarifications

### AC3 — Room Types (Deferred/Placeholder)
The rooms table, repository, service, and API endpoint (`GET /conferences/{slug}/rooms`) do **NOT exist yet** — they will be implemented in Epic 3. For this story, the `info` command output should include a placeholder section for rooms that displays `"No room information available yet."`. The command should be structured so that room data can be added later without refactoring the core info flow.

### AC4 — Context Support (Out of Scope)
Context management (`unconf checkout <slug>`) is Story 2.4. For this story, the slug argument is **required** — `unconf info` without an argument must return a usage error. When context support is added in Story 2.4, the `info` command will gain the ability to fall back to the current context conference when no argument is provided.

### Client Pattern

[Source: internal/client/client.go]

The `*Client` struct uses resty. For public endpoints (no auth):

```go
func (c *Client) GetConference(ctx context.Context, slug string) (*ConferenceResponse, error) {
    var result ConferenceResponse
    var errEnvelope apiErrorEnvelope

    resp, err := c.http.R().
        SetContext(ctx).
        SetResult(&result).
        SetError(&errEnvelope).
        Get("/conferences/" + slug)
    if err != nil {
        return nil, fmt.Errorf("failed to get conference: %w", err)
    }

    if resp.StatusCode() == http.StatusNotFound {
        return nil, ErrConferenceNotFound
    }

    if resp.IsError() {
        return nil, fmt.Errorf("failed to get conference: %s (HTTP %d)", errEnvelope.Error.Message, resp.StatusCode())
    }

    return &result, nil
}
```


Date formatting follows the same pattern as `list.go`: parse `"2006-01-02"`, display as `"Oct 07 - Oct 10, 2026"`.
