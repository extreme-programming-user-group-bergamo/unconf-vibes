# Story 2.2: CLI List Command

**Status:** Done

**Epic:** 2 - Conference Discovery & Context

---

## Story

**As an** attendee,
**I want** to run `unconf list` to see available conferences,
**so that** I can discover unconferences I might attend.

---

## Acceptance Criteria

1. `unconf list` displays conferences in a formatted table
2. Table shows: name, dates, location, attendee count, status
3. Results sortable by date (default: upcoming first)
4. `--all` flag shows past conferences (default: only upcoming/active)
5. Empty state message if no conferences available
6. Works without authentication (public data)

### CLI Command Patterns

- **Interface-based DI:** Each command defines a local interface for its dependencies (e.g., `StatusClient` in `status.go`, `AuthClient` in `login.go`). The `list` command should define `ListClient` with `ListConferences` method.
- **Constructor pattern:** `newXxxCmd(dep XxxClient) *cobra.Command` → `RunE` calls `runXxx(cmd, dep, flags...)`
- **Output:** Use `cmd.OutOrStdout()` for normal output, `cmd.ErrOrStderr()` for errors
- **Test pattern:** Mock struct with function fields, construct command with `newXxxCmd(mock)`, capture output via `cmd.SetOut(&buf)`, execute and assert

### Client Patterns

- **File:** `internal/client/client.go`
- **Public methods** (no auth): Use `c.http.R().SetContext(ctx).SetResult(&result).SetError(&errEnvelope).Get("/path")`
- **Auth methods:** Add `.SetHeader("Authorization", "Bearer "+token)` — NOT needed for `ListConferences`
- **Error handling:** Check `resp.IsError()`, return `fmt.Errorf("failed to X: %s (HTTP %d)", errEnvelope.Error.Message, resp.StatusCode())`
- **Response types:** Defined in same file (e.g., `DeviceFlowResponse`, `TokenResponse`, `UserResponse`)

### Route Structure

- `internal/api/routes.go` — `GET /conferences` and `GET /conferences/:slug` already registered as public routes (no auth middleware)
- The CLI client hits these endpoints directly via the base `apiClient`

### Key Implementation Details

- **Date parsing in CLI:** API returns dates as `"2006-01-02"` strings. Parse with `time.Parse("2006-01-02", dateStr)` for sorting and display formatting.
- **Display date format:** `"Jan 02 - Jan 05, 2026"` — use `startDate.Format("Jan 02")` and `endDate.Format("Jan 02, 2006")`
- **Filtering logic:** Compare `conference.Status` string against `"past"` — simple string comparison, no need to re-derive
- **Sorting logic:** Parse `StartDate` to `time.Time` for comparison in sort function, ascending order
- **Tabwriter:** Use `tabwriter.NewWriter(out, 0, 0, 2, ' ', 0)` for clean column alignment
